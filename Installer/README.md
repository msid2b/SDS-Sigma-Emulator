## INSTALLER
Download and unzip the Siggy-App installation package.  Copy or move siggy.app to the Applications directory.
You can create a new sigma virtual machine using the PO tape (CPF0.tap) in the Tapes folder, or alternatively, download the BIG.siggy virtual machine and unzip it to a suitable location.  BIG.siggy has been booted with the PO tape and is ready to be booted from the RAD (2F0).  It is configured with 1024KW of memory, 4 RAD devices, 16 disks, 4 tapes.
